🚀 התקנה בפקודה אחת: אשף אינטראקטיבי, שרת MCP ואוטומציה

צריכים לטפל בקובצי וידאו שלמים (.mkv / .mp4), עונות שלמות, או לחבר את סוכן ה-AI ושרת המדיה שלכם? בחרו את סביבת העבודה שלכם:

1. התקנה גלובלית (Homebrew או סקריפט מהיר)

brew tap omerninyo/tap && brew install rightsub

או בהתקנה ישירה מ-GitHub: git clone https://github.com/omerninyo/RightSub.git && cd RightSub && ./install.sh

2. הפעלת האשף האינטראקטיבי ואשף ההקמה (ללא דגלים!)

rightsub          # פותח תפריט אינטראקטיבי + גרירת קבצים ודפדפן מובנה
rightsub setup    # אשף בדיקת מערכת, מפתחות, Hooks ושירות רקע

1. מתקין אוטומטי לחלונות (מוסיף ל-PATH של המשתמש אוטומטית)

git clone https://github.com/omerninyo/RightSub.git
cd RightSub
install.bat

install.bat בודק Python ו-FFmpeg, מתקין תלויות ורושם את rightsub ב-PATH של המשתמש ללא צורך בהרשאות Administrator.

2. הפעלה מכל חלון CMD או PowerShell

rightsub
rightsub auto "C:\Media\Movie.mkv"

1. רישום אוטומטי לכל סוכני ה-AI בפקודה אחת

rightsub mcp --install
rightsub mcp --status

מזהה ורושם אוטומטית את שרת ה-MCP המקומי (8 כלים) ב-Google Antigravity, Claude Desktop, Cursor, Windsurf ו-Claude Code (כולל גיבוי .bak והזרקת PATH מלאה).

2. דברו עם הסוכן שלכם בשפה טבעית

"בדוק את תיקיית המדיה שלי ב-/Volumes/Media/Show, תקן את כל כתוביות העברית לפלקס במצב Seed-Safe, ואם חסר תרגום לפרק — חלץ את האנגלית ותרגם."

1. מחולל Hooks ושירותי רקע אוטומטי

rightsub config --install-hooks
rightsub config --install-service

מייצר סקריפטים מוכנים ל-qBittorrent ול-Transmission ב-~/.config/rightsub/hooks/, רושם Webhook חי ב-Sonarr/Radarr, ומתקין שירות רקע (launchd / systemd / schtasks).

2. שרת Webhook לקונטיינרים ו-NAS (Port 8775)

rightsub serve --port 8775 --path-map "/data/media:/media" --seed-safe

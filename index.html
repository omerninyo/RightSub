מה RightSub עושה בפועל

המערכת מפרידה בין שני מנועים עצמאיים: מנוע מאסטרינג דטרמיניסטי לכתוביות קיימות (SubRefine), ומנוע תרגום והגהה מבוסס סוכני AI (SubSwarm).

01 / SUBREFINE 100% דטרמיניסטי · 0 טוקנים

תיקון כיווניות (BiDi) וביטול היפוכי Subabi

נגנים כמו Plex ו-Apple TV מציגים סימני פיסוק בסוף משפט עברי (?, !, .) בצד ימין של השורה. בנוסף, אלפי כתוביות ישנות ברשת עברו "היפוך ויזואלי" (Subabi) שהפך פיזית את הנקודות והסוגריים בקובץ. RightSub מזהה את קוטביות הקובץ, משחזר 18 תבניות היפוך ישנות, ועוטף כל שורה בתווי RLM (\u200F) לפי תקן Unicode UAX #9 Rule N1.

02 / ENCODING & CLEANUP 100% דטרמיניסטי · 0 טוקנים

הצלת קידוד Windows-1255, הומוגליפים והצלבת מספרים

זיהוי אוטומטי ברמת הבייטים של קובצי CP1255 / ISO-8859-8 והמרתם ל-UTF-8 תקני. ניקוי תווים זרים שהסתננו למילים בעברית מ-7 מערכות כתב (כגון האות הגאורגית ב-דეייט ← דייט), הסרת שורות פרסומת וקרדיטים, והיפוך חזרה של מספרים דו-ספרתיים (84 ← 48) בהצלבה מול כתובית באנגלית.

03 / SEED-SAFE TORRENTS הגנת טורנט פעילה

זיהוי עברית לפי תוכן ושמירת .he.srt נפרד

הורדתם סרט עם קובץ Movie.srt רגיל (ללא סיומת .he.srt) או תיקיית Subs/? RightSub סורקת את תוכן הקובץ, מזהה שמדובר בעברית, משאירה את קובץ ה-.srt המקורי ללא שום שינוי בדיסק כדי לא לשבור שיתוף טורנט ב-qBittorrent/Transmission, ושומרת קובץ Movie.he.srt מתוקן לצד הווידאו.

04 / SUBSWARM & MCP סוכני AI / Ollama

תרגום מאנגלית לעברית וחיבור MCP לסוכני AI

כאשר אין כתוביות בעברית כלל, RightSub מחלצת כתוביות מובנות מ-.mkv/.mp4 (או מתמללת שמע מקומית), בונה מילון דמויות ומגדר מ-TMDb (את/היא מול אתה/הוא), ומתרגמת בהתאמת שורות 1:1 דרך שרת ה-MCP המובנה (Claude, Cursor, Antigravity), Gemini או Ollama מקומי.

CLI · WIZARD · MCP SERVER

התקנה לעבודה מקומית, עונות שלמות ואוטומציה

מעבר לכלי הדפדפן, ניתן להתקין את חבילת ה-CLI המלאה הכוללת אשף אינטראקטיבי לטרמינל ול-CMD, חיבור לסוכני AI בפקודה אחת (rightsub mcp --install), ואוטומציה ל-qBittorrent / Sonarr / Bazarr.

STEP 01

התקנה בפקודה אחת (Homebrew או סקריפט)

brew tap omerninyo/tap && brew install rightsub

או ישירות מ-GitHub: git clone https://github.com/omerninyo/RightSub.git && cd RightSub && ./install.sh

STEP 02

הפעלת האשף האינטראקטיבי או תיקון אוטומטי

rightsub                        # תפריט אינטראקטיבי + גרירת קבצים
rightsub auto ~/Movies/Season1  # תיקון/תרגום אוטומטי לתיקייה שלמה
STEP 01

מתקין אוטומטי לחלונות (רישום אוטומטי ל-PATH)

git clone https://github.com/omerninyo/RightSub.git
cd RightSub
install.bat

install.bat מאמת Python ו-FFmpeg ומוסיף את rightsub ל-PATH של המשתמש ללא צורך בהרשאות Administrator.

STEP 02

הרצה מכל חלון CMD או PowerShell

rightsub
rightsub auto "C:\Media\Movie.mkv"
STEP 01

רישום אוטומטי לכל סוכני ה-AI בפקודה אחת

rightsub mcp --install
rightsub mcp --status

מזהה ורושם אוטומטית את שרת ה-MCP המקומי (8 כלים) ב-Google Antigravity, Claude Desktop, Cursor, Windsurf ו-Claude Code.

STEP 02

הנחיית הסוכן בשפה טבעית

"בדוק את תיקיית המדיה ב-⁦/Volumes/Media/Show⁩, תקן את כתוביות העברית לפלקס במצב Seed-Safe, ואם חסר תרגום — חלץ את האנגלית ותרגם."
STEP 01

מחולל Hooks ושירותי רקע אוטומטי

rightsub setup
rightsub config --install-hooks

מייצר סקריפטים מוכנים ל-qBittorrent ול-Transmission ב-~/.config/rightsub/hooks/, רושם Webhook ב-Sonarr/Radarr, ומתקין שירות רקע.

STEP 02

שרת Webhook ו-Web UI מקומי (Port 8775)

rightsub serve --port 8775 --path-map "/data/media:/media" --seed-safe

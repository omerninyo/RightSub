# אפיון עלילה, דמויות, מגדר ודיאלקט (אינטגרציית TMDb)

פרויקט RightSub משלב את ממשק ה-API של **The Movie Database (TMDb)** לצורך זיהוי עובדתי ודטרמיניסטי של דמויות, שיוך מגדרי מדויק לשחקני אורח, חילוץ תקצירי עלילה והזרקת הנחיות דיאלקט (בריטי/אמריקאי) ומשלב לשוני.

- **ספק נתונים**: [The Movie Database (TMDb)](https://www.themoviedb.org)
- **תיעוד API רשמי**: [TMDb API Documentation](https://developer.themoviedb.org/docs)
- *הבהרת זכויות*: מוצר זה משתמש ב-API של TMDb אך אינו מאושר או מאומת רשמית על ידי TMDb.

---

## 🎯 הבעיות הנפתרות בעזרת השילוב

1. **שיוך מגדרי דטרמיניסטי (מניעת שגיאות פנייה ישירה בעברית)**:
   - בעברית, כל פנייה ישירה בגוף שני ("אתה" לעומת "את") וכל נטיית פעלים ותארים תלויים לחלוטין במגדר של הדובר והשומע.
   - דמויות ראשיות מוכרות למודל, אך **שחקני אורח מתחלפים בכל פרק** (עדים, לקוחות, רופאים, שופטים) ונושאים לעיתים שמות יוניסקס (Terry, Jordan, Robin, Pat, Dr. Adams).
   - TMDb מספק קוד מגדר רשמי עבור כל שחקן קבוע ושחקן אורח (`1 = נקבה`, `2 = זכר`), המומר ישירות לכינויי גוף תקניים (`את/היא` מול `אתה/הוא`).

2. **תקציר פרק והכנת הקשר למודל התרגום (Context Priming)**:
   - שליפת התקציר המדויק של הפרק (`overview`) והזרקתו לבלוק ה-Context של הפרומפט.
   - מאפשר למודל התרגום להבין מראש את מוקד העלילה ולמנוע תרגום שגוי של מונחים דו-משמעיים (כגון מונחים משפטיים או רפואיים).

3. **זיהוי שפת מקור, ארץ מוצא והנחיות דיאלקט (Dialect Directives)**:
   - זיהוי אוטומטי של ארץ המקור (`GB` / בריטניה לעומת `US` / ארצות הברית).
   - הזרקת הנחיות סלנג וביטויים בריטיים (למשל מניעת תרגום שגוי של `pissed` ככעס במקום שיכור, או `cheers` כלחיים במקום תודה).
   - זיהוי ז'אנרים (משפטי, רפואי, מד״ב) לאכיפת מילון מונחים תקני.

## ⚙️ התקנה והגדרת מפתח גישה

TMDb מעניקה מפתח API בחינם לשימוש אישי:

1. פתחו חשבון משתמש חינמי באתר [themoviedb.org](https://www.themoviedb.org/signup).
2. עברו אל **Settings > API** וצרו מפתח API (גרסה 3 או Read Access Token גרסה 4).
3. הגדירו את המשתנה בטרמינל המקומי:
   ```bash
   export TMDB_API_KEY="your_api_key_or_bearer_token"
   ```
   *(מומלץ להוסיף שורה זו לקובץ ההגדרות `~/.zshrc`)*.

### מנגנון נסיגה בטוח (Graceful Degradation)
אם המשתנה אינו מוגדר, RightSub ממשיכה לפעול בצורה חלקה ומחלצת שמות באופן מקומי מתוך קובץ ה-SRT כפי שפעלה בעבר, ללא קריסות או שגיאות.

## 🚀 פקודות שימוש ודוגמאות

### 1. בדיקת מטא-דאטה ישירות מקובץ וידאו או שם כותר
```bash
python3 scripts/tmdb_client.py "Boston.Legal.S01E05.1080p.mkv"
```
או לפי שם, עונה ומספר פרק:
```bash
python3 scripts/tmdb_client.py "Boston Legal" -s 1 -e 5
```

### 2. הפקת Translation Bible מועשר במגדר מאומת
חילוץ שמות מתוך קובץ הכתוביות באנגלית ושילובם עם הדמויות מ-TMDb:
```bash
python3 scripts/03_generate_bible.py "Boston Legal S01E05.en.srt" --tmdb -o translation_bible.json
```
או דרך פקודת ה-CLI המרכזית:
```bash
./rightsub bible "Boston Legal S01E05.en.srt" --tmdb
```

### 3. בניית פרומפטים מונחי הקשר ודיאלקט
כאשר `09_prompt_builder.py` רץ עם ה-Bible שנוצר, הוא מזריק אוטומטית את תקציר הפרק, הנחיות הדיאלקט ורשימת הדמויות עם המגדר המאומת:
```bash
./rightsub prompt-gen "Boston Legal S01E05.en.srt" -b translation_bible.json
```

# תמלול מקומי On-Device וסנכרון מונחה שמע (אינטגרציית quicksubs)

פרויקט RightSub משלב את **`quicksubs`**, כלי שורת פקודה מתקדם לתמלול מקומי על גבי macOS שפותח על ידי **Matt Birchler**.

- **מחבר**: Matt Birchler
- **מאגר GitHub**: [mattbirchler/quicksubs](https://github.com/mattbirchler/quicksubs)
- **אתר המחבר**: [Birchtree](https://birchtree.me)
- **אפליקציית Mac מקבילה**: [Quick Subtitles](https://quickstuff.app)

---

## סקירה כללית

מערכת RightSub מתמחה בתרגום כתוביות ברמת אולפן, עיצוב דו-כיווני (BiDi/RLM עבור Plex ו-Infuse), ובקרת התאמת מגדר קפדנית. השילוב עם `quicksubs` מעניק לפרויקט **יכולות Speech-to-Text מקומיות ישירות על גבי החומרה של ה-Mac**:

1. **חילוץ ותמלול מקור כשאין כתוביות (תרחיש 1)**: תמלול אוטומטי של קובצי וידאו ואודיו לכתוביות `.srt` תקניות ללא צורך בהורדת כתוביות מהרשת.
2. **סנכרון תזמונים מונחה שמע (תרחיש 2)**: כיול מחדש של כתוביות שיצאו מסנכרון (עקב הבדלי FPS או גרסאות שידור) באמצעות תזמוני עוגן אמיתיים ישירות מרצועת השמע.

---

## התקנה ב-macOS

הכלי `quicksubs` מופץ כחבילת Homebrew:

```bash
brew install mattbirchler/tap/quicksubs
```

*הערה: RightSub מתוכנן בצורה מודולרית. אם הכלי אינו מותקן במחשב, המערכת תמשיך לפעול כרגיל עם שאר מנגנוני ה-FFmpeg והתרגום.*

## מנועי תמלול מקומיים נתמכים

| מנוע | דגל הפעלה | משקל מודל | תיאור ומאפיינים |
| :--- | :--- | :--- | :--- |
| **Apple SpeechAnalyzer** | `--engine apple` | 0 MB (מובנה) | רץ ישירות על ה-Neural Engine של Apple Silicon. מהיר במיוחד וללא צורך בהורדה (ברירת מחדל). |
| **OpenAI Whisper** | `--engine whisper` | ~626 MB | דיוק מקסימלי לתכנים מורכבים או הקלטות שמע מאתגרות. |
| **NVIDIA Parakeet** | `--engine parakeet` | ~400 MB | מודל עצבי מקומי קל משקל ומהיר. |

## תרחישי שימוש מיושמים

### 1. תמלול ויצירת כתוביות מקור (STT Ingestion)
כאשר קובץ וידאו חסר כתוביות מוטמעות (MKV/MP4) ואין לו קובץ כתוביות חיצוני בתיקייה:

#### אפשרות א': הפעלת כלי התמלול הייעודי
```bash
python3 scripts/00_transcribe_audio.py "/path/to/video.mp4" -e apple
```
הפקודה תיצור קובץ `/path/to/video.srt` מקומית בתוך שניות/דקות בודדות, ללא תעבורת רשת.

#### אפשרות ב': הפעלה כחלופה (Fallback) אוטומטית במנגנון החילוץ
```bash
python3 scripts/01_extract_subtitles.py "/path/to/season_folder" --transcribe --engine apple
```
אם `01_extract_subtitles.py` אינו מוצא כתוביות קיימות, הוא מפעיל אוטומטית את `quicksubs` ומייצר `.en.srt` המוכן מיידית לפייפליין התרגום של RightSub.

---

### 2. סנכרון תזמונים מונחה שמע (Audio-Guided Sync)
כאשר קיים קובץ כתוביות מתורגם (למשל `.he.srt` בעברית), אך התזמונים שלו אינם מסונכרנים עם הווידאו (עקב הבדלי 23.976 מול 25 FPS, קטעי פתיח חתוכים או מעברוני פרסומות):

```bash
python3 scripts/16_audio_align_sync.py \
  "path/to/unsynced.he.srt" \
  -o "path/to/aligned.he.srt" \
  -v "path/to/video.mp4" \
  -e apple
```

**אופן הפעולה האלגוריתמי**:
1. `quicksubs` מפיק תזמוני דיבור מדויקים מפס הקול של הווידאו לקובץ עוגן זמני.
2. מנוע `16_audio_align_sync.py` מזהה את ההיסט ההתחלתי ואת יחס המתיחה הליניארי (Scale Ratio).
3. תזמוני הכתובית מכוילים מחדש תוך שמירה מלאה על כל הטקסט העברי, תווי ה-RLM והעיצוב המקורי.

## מפת דרכים עתידית (Future Roadmap)

התרחישים הבאים מתוכננים להרחבה בגרסאות הבאות:

### 3. מזעור רוחב פס ועלויות ענן (Zero-Bandwidth Cloud Optimization)
תמלול מקומי של ספריות וידאו כבדות (גיגה-בייטים) על גבי ה-Mac, ושליחת קובצי הטקסט הזעירים בלבד (קילובייטים) ל-LLM בענן (Google Gemini), תוך חיסכון של 99% בעלויות רוחב הפס והטוקנים.

### 4. אוטומציית רקע לשרת מדיה (Plex/Infuse Auto-Captioner)
הגדרת LaunchAgent או Folder Action ב-macOS המנטר תיקיית הורדות מדיה:
- זיהוי קובצי וידאו חדשים ללא כתוביות.
- הפעלת `quicksubs` ברקע להפקת כתוביות.
- עיבוד כתוביות אוטומטי ב-RightSub (החלת RLM, טיפוגרפיה ותרגום).

### 5. תמלול פודקאסטים והקלטות קוליות מקומיות
פייפליין עצמאי לתמלול הרצאות, ראיונות ופודקאסטים ישירות לטקסט ולכתוביות.

### 6. מדידת ביצועי הסקה בחומרת Apple Silicon
שילוב פקודת `quicksubs bench` למדידת ביצועי Neural Engine מול GPU על גבי מעבדי M-series, לבחירת המנוע האופטימלי ביותר לעיבוד סדרות שלמות ב-Batch.

# מפרט ארכיטקטוני לפיתוח עתידי: ממשק אינטראקטיבי בשורת הפקודה (Interactive CLI Wizard)

מסמך זה מתעד את עקרונות התכנון, הארכיטקטורה ודרישות המערכת עבור מימוש עתידי של ממשק אינטראקטיבי (TUI / Interactive Wizard) עבור **RightSub**. מטרת הממשק היא לאפשר למשתמשי קצה להפעיל את מלוא יכולות המערכת ללא צורך בידיעת פקודות או דגלים (Flags).

---

## 1. מטרות הפרויקט (Project Objectives)

1. **אפס סיבוך וזכירת דגלים:** המשתמש מריץ `./rightsub` ללא ארגומנטים ומובל שלב-אחר-שלב באמצעות שאלות פשוטות, תפריטים ובחירה בחצים או במספרים.
2. **תמיכה מובנית ב-Drag & Drop:** שורת הקלט מאפשרת גרירה ישירה של קובץ וידאו, כתובית או תיקייה מתוך מנהל הקבצים (Finder ב-macOS, סייר הקבצים ב-Windows).
3. **ברירת מחדל לא-הרסנית (Seed-Safe First):** הגנה מוחלטת על קובצי טורנט משותפים כברירת מחדל, עם אפשרות ברורה לבחירה בשינוי שם במקום.
4. **עצמאות מלאה (Zero Mandatory Dependencies):** הימנעות מספריות GUI כבדות או תלויות הדורשות התקנת רכיבי מערכת מורכבים.

---

## 2. התחשבות בפלטפורמות שונות (Platform Awareness & OS Constraints)

המערכת תזהה את מערכת ההפעלה בזמן ריצה באמצעות `platform.system()` ותתאים את הממשק והיכולות המוצגות:

| רכיב / יכולת | macOS | Windows | Linux / NAS |
| :--- | :--- | :--- | :--- |
| **תמלול קולי (Speech-to-Text)** | מנוע `Apple SpeechAnalyzer` (דרך `quicksubs -e apple`). מהיר במיוחד ומשתמש ב-Apple Silicon Neural Engine. | מנוע `Whisper` בלבד (או הצגת הודעה שהתמלול הקולי אינו נתמך ללא התקנת בינארי Whisper). | מנוע `Whisper` בלבד (או הפניה לתמלול חיצוני). |
| **גרירת נתיבים (Path Drag & Drop)** | ה-Finder מוסיף תווי בריחה לרווחים (`\ `) או גרשיים. הממשק ינרמל את הנתיב באמצעות `shlex` ו-`os.path.expanduser`. | נתיבים מועתקים עם קווים נטויים אחוריים (`\`) או גרשיים כפולים. הממשק ינרמל באמצעות `pathlib.Path`. | תמיכה בנתיבי POSIX סטנדרטיים. |
| **קידוד טרמינל** | UTF-8 כברירת מחדל. | דורש וידוא קידוד UTF-8 בטרמינל (`chcp 65001`) למניעת ג'יבריש בהצגת טקסט עברי בממשק. | UTF-8 כברירת מחדל. |

---

## 3. שפה וכיווניות בטרמינל (Terminal BiDi & Layout Architecture)

אחד הכשלים הנפוצים בממשקי טרמינל מרובי-עמודות (Full TUI Dashboard) בעברית הוא שבירת מסגרות ASCII עקב פענוח לקוי של רוחב תווי Unicode ועברית בטרמינלים שונים (Terminal.app לעומת iTerm2 לעומת Windows Terminal).

**העקרונות שנבחרו לממשק RightSub:**
1. **מבנה רשימה לינארי שורה-אחר-שורה (Linear Wizard):**
   - שימוש בתפריטים אנכיים פשוטים במקום תיבות ASCII קשיחות וטבלאות מורכבות.
   - הדפסה רציפה שאינה תלויה במנועי רינדור מסך מורכבים (כמו `curses` או `textual`), המבטיחה תאימות ב-100% מהטרמינלים, כולל חיבורי SSH ו-tmux.
2. **שילוב שפות ברור:**
   - תוויות טכניות ומקשים מוצגים באנגלית נקייה או בניסוח דו-לשוני קצר, כדי למנוע היפוך סימני פיסוק וסוגריים בתוך שורות הטרמינל.

---

## 4. ניהול מפתחות ואבטחה (Secure Key & Configuration Management)

הממשק האינטראקטיבי לא ידרוש הזנת מפתחות בכל הפעלה, ולא יחייב את המשתמש לערוך קובצי מערכת.

1. **קובץ קונפיגורציה מקומי:**
   - נשמר בנתיב: `~/.config/rightsub/config.json`.
   - נוצר עם הרשאות אבטחה מחמירות: `chmod 600` (קריאה וכתיבה למשתמש הנוכחי בלבד).
2. **מדרג עדיפות (Hierarchy of Precedence):**
   - משתנה סביבה בטרמינל (`export TMDB_API_KEY="..."`) -> קובץ מקומי -> פעולה ללא מפתח.
3. **הזנה מוסתרת ובדיקת תקינות (Masked Input & Live Ping):**
   - בעת הזנת מפתח API, הקלט מוסתר באמצעות `getpass` כדי שלא יירשם בהיסטוריית הפקודות.
   - מיד עם ההזנה, המערכת מבצעת בדיקת חיבור מהירה (Ping) לשרת הרלוונטי (TMDb / Gemini) ומאשרת שהמפתח תקין לפני שמירתו.
4. **עבודה מלאה ללא מפתחות (Offline-First):**
   - כל פעולות הליבה (תיקוני BiDi, RLM, CP1255, ניקוי פרסומות, תמלול מקומי) פועלות ללא שום צורך במפתח.

```text
    5. תמלול שמע לכתוביות (On-Device Speech-to-Text)

  > /Volumes/Media/Gladiator (2000)/Gladiator.mkv

[?] זוהה קובץ וידאו ללא כתובית עברית חיצונית.
    כיצד לפעול?
  > [1] חילוץ כתובית אנגלית מוטמעת ותרגום (מומלץ)
    [2] סריקת שמע ותמלול מקומי באמצעות AI
    [3] ביטול

  > [Y] כן, שכפל לקובץ חדש והשאר את המקור ללא נגיעה (מומלץ)
    [N] לא, החלף ושנה את שם המקור
```

## 6. ספריות וטכנולוגיות מומלצות למימוש

1. **אפשרות מועדפת (Zero Dependencies):**
   - מימוש באמצעות ספריות הליבה של Python בלבד (`sys`, `os`, `pathlib`, `shlex`, `getpass`).
   - מבטיח הפצה מיידית ללא צורך בהתקנת חבילות נוספות דרך `pip`.
2. **אפשרות משופרת (Rich Terminal UI):**
   - שימוש בספריית `questionary` או `InquirerPy`.
   - מעניקה חוויית חצים צבעונית, רשימות בחירה עם מקש רווח (Multi-select), והסתרת סיסמאות אינטואיטיבית.
